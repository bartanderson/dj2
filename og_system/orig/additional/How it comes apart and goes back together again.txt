YOUR ARCHITECTURE vs. THE JSON
Table

KEY ADJUSTMENTS FOR YOUR MODEL
1. State Machines → Actual Code
Don't give the AI the state machine JSON. Implement it:
Python
Copy
class CombatEngine:
    STATES = {
        'setup': SetupPhase,
        'initiative': InitiativePhase,
        'turnCycle': TurnCyclePhase,
        # ...
    }
    
    def transition(self, event):
        # JSON defines valid transitions
        # Code enforces them
        current = self.db.get_state()
        valid = self.json_rules['state_machines']['encounter']['transitions'][current]
        if event not in valid['on']:
            raise InvalidTransition
        return self.STATES[valid['to']]()
The JSON is validation and documentation. The code is execution.
2. Procedures → Function Registry
Python
Copy
PROCEDURES = {
    'resolveAttack': resolve_attack,
    'resolveSpell': resolve_spell,
    'rollEncounter': roll_encounter,
    # ...
}

def execute(procedure_name, context):
    """AI requests 'resolveAttack', code runs it, returns result"""
    proc = PROCEDURES[procedure_name]
    return proc(context, db)
