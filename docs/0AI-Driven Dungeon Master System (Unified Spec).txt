1. Core Principle

All gameplay emerges from deterministic simulation, shaped by constrained AI judgment, and presented through multimodal systems.

2. System Philosophy (Non-Negotiable)
2.1 Separation of Powers
Layer	Responsibility

2.2 Hard Rules

The AI (LLM) must NOT:

roll dice
mutate world state
invent outcomes

The AI MAY:

interpret intent
select actions/tools
determine if a roll is needed
suggest difficulty (bounded)
shape pacing and tone
control information exposure

7.2 Adjudication Engine

Validates and converts decisions into executable actions.

def process(decision):
    if decision.type == "check":
        return {
            "tool": "roll_check",
            "args": {
                "skill": decision.skill,
                "difficulty": clamp(decision.difficulty + decision.difficulty_adjustment)
            }
        }

13. Phase Orchestrator (Global Control)
class PhaseOrchestrator:

    def run_turn(self, user_input):

        text = self.input_phase(user_input)

        decision = self.adjudication_phase(text)

        action = adjudication_engine.process(decision)

        result = session_manager.handle_action(
            action["tool"], action["args"]
        )

        ctx = context_builder.build(world_state, session_state)

        narrative = narrative_engine.describe(ctx, result)

        text = llm_format(narrative)

        tts.play(text)

        audio.update(ctx)
        visuals.update(ctx)

        self.progression_phase(ctx, decision)
