# Event Taxonomy

All significant game actions and world changes are recorded as events. Each event has a `type` (domain.entity.phase), `data` (dict), `source` (string), and `timestamp`.

## Domains

- **movement** – spatial changes
- **perception** – what entities sense
- **interaction** – social, trade, dialogue
- **combat** – conflict resolution
- **sound** – audio events
- **state** – direct world mutations
- **system** – engine meta‑events
- **encounter** – contextual boundaries
- **escalation** – world reactions
- **environment** – weather, lighting, terrain
- **latent** – AI inferences (generated by DM)

## Usage

- **Event Log** records every event.
- **Escalation Engine** listens to event patterns and triggers actions.
- **ContextBuilder** filters events when building the perception snapshot for the LLM.
- **Combat, Dialogue, etc.** emit events for escalation and context.
